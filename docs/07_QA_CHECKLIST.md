- [ ] Atreides is described as decision support.
- [ ] Final decisions remain with humans.
- [ ] No guarantee of incident prevention.
- [ ] No fake accuracy metrics.
- [ ] No fake customers, testimonials or pilots.
- [ ] No facial recognition claim.
- [ ] No biometric identification claim.
- [ ] No autonomous intervention claim.
- [ ] Planned features are not represented as already deployed.

## Accessibility

- [ ] Semantic header, main and footer.
