# Product and Positioning

## Name

**Atreides**

## Category

AI-powered Venue Intelligence / Security Decision Support.

## One-sentence description

Atreides analyzes live data from existing security cameras and helps venue security teams identify potentially critical situations, unusual crowd dynamics and heavily stressed areas earlier.

## Longer description

Atreides is an AI-powered Venue Intelligence platform for clubs, festivals, beer tents, event halls and other venues. The system analyzes live data from existing security cameras and presents prioritized alerts, heatmaps and contextual information in a central operational dashboard.

The purpose is not to automate security decisions. Atreides helps human teams direct attention to relevant areas, assess situations more quickly and coordinate responses based on better situational awareness.

## Core principle

**Atreides supports people; it does not replace their judgment.**

The platform:

- supports security personnel
- prioritizes possible risk situations
- provides context
- helps monitor several areas at once
- keeps final assessment and action with humans

The platform must not be described as:

- automatically deciding who is dangerous
- autonomously intervening
- predicting crime
- identifying people biometrically
- guaranteeing that incidents will be prevented

## Target users

Primary:

- club operators
- festival organizers
- beer-tent operators
- event-hall operators
- venue security managers
- private security companies

Secondary:

- event production companies
- stadium and arena operators
- large hospitality venues
- infrastructure and safety partners

## Main problems

- One team cannot actively watch every camera feed at all times.
- Critical situations often develop gradually.
- Crowd density and movement can change quickly.
- Security personnel need prioritization, not more raw video.
- Existing camera infrastructure often creates data without actionable overview.

## Main value proposition

Atreides turns existing camera data into a clearer, prioritized operational picture for human security teams.

## Current product status language

Until the owner confirms otherwise, use wording such as:

- “in development”
- “designed for”
- “planned pilot program”
- “we are speaking with selected venues”
- “the platform is intended to”

Do not use:

- “already deployed”
- “proven”
- “used by”
- “prevents”
- “detects with X% accuracy”
- named customer references
